# DevDashboard

Panel web en desarrollo para organizar y visualizar proyectos de desarrollo.

## Objetivo

Practicar la construcción de interfaces con React y presentar información de proyectos de forma clara, incluyendo su estado y avance.

## Tecnologías

- React 19
- Vite
- JavaScript
- Chart.js
- react-chartjs-2

## Ejecutar localmente

Requisitos: Node.js y npm.

```bash
git clone https://github.com/0FF000-creator/DevDashboard.git
cd DevDashboard
npm install
npm run dev
```

Abre la URL local que Vite muestra en la terminal.

## Estado

Proyecto personal en desarrollo. La estructura y las funcionalidades pueden cambiar mientras se practican componentes, manejo de datos e integración de gráficas.

## Propósito de aprendizaje

Este proyecto forma parte de mi práctica de desarrollo frontend y sirve como espacio para experimentar con React, organización de componentes y visualización de datos.
